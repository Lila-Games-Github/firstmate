==================== ACT 3: the deadlock that was left behind - two records, one slot ====================

# so the scout's record names it too and now holds its claim, while the
# pipeline's record still names the same copy. The scout has finished and
# its report is in the firstmate home; the pipeline task landed long ago.
# (the spawn that took the slot re-prepared it onto a detached base, which
# is what replaced the pipeline branch checkout in the incident)
